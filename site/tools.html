Tools and prompts

69 tools and 7 guided prompts, generated from the server's own definitions.

Read-only tools only read. Write tools add data and need write mode. Destructive tools overwrite or delete data that YNAB can't restore. In read-only mode the server hides every write tool. The same data is available as tools.json.

This list is generated when the site is built. Run npm run build && node scripts/build-site.mjs and open _site/tools.html, or see the tool list in the README.

Prompts

Prompts are guided workflows grounded in YNAB's method. Each one runs several tools and walks through the results. Clients that support MCP prompts list them, often as slash commands.

The prompt list is generated when the site is built.
